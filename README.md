# 📦 Smart Inventory Management System

A full-stack Inventory Management System designed to track stock levels, manage products, and perform real-time CRUD operations. Built with **Java Spring Boot** and **MS SQL Server**.

## 🚀 Key Features
* **Real-time Dashboard:** View total products and system status instantly.
* **CRUD Operations:** Create, Read, Update, and Delete products seamlessly.
* **Database Integration:** Connected to **MS SQL Server** for robust data storage.
* **REST API:** Fully functional API endpoints handling requests.
* **Responsive UI:** A clean web interface built with HTML, CSS, and JavaScript.

## 🛠️ Tech Stack
* **Backend:** Java 21, Spring Boot 3.x (Spring Web, Spring Data JPA).
* **Database:** Microsoft SQL Server.
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
* **Tools:** NetBeans / IntelliJ IDEA, Maven.
